# 阿猛数字陪伴项目

阿猛是为 FoloToy AI Passport 制作的纪念型电子宠物。项目坚持“本地逻辑优先”：设备上的确定性状态机决定阿猛现在的感受和行为；可选 AI 只负责组织表达，不得覆盖本地状态，也不得编造生前经历。

## 角色锚点

角色设计来自主人提供的照片与文字档案，开发时必须保留这些辨识特征：

- 长毛白猫，头顶有淡黄色不规则毛块，尾巴偏黄。
- 左上唇上方有一小块黄色毛。
- 浅绿色眼睛、狮子般的大头、肥硕身体和浑圆爪子。
- 第一眼警惕、清高、不屑；熟悉以后却很亲密，形成明显反差。
- 招牌行为包括：听见呼唤后回应并跑来、绕腿蹭、两只前爪搭腿、埋头吃饭、晒太阳午睡、享受挠下巴，以及认真埋伏后扑大鸟玩具。

## 产品规则

1. 饥饿、精力、心情、信任、亲密、习惯和当前行为均由本地状态决定。
2. AI 对话层只接收一个紧凑、事实化的状态快照，只能决定“怎么说”。
3. AI 不得生成档案中不存在的生前记忆。
4. 离线时电子宠物仍然完整可用；网络或 AI 失败时回退到本地行为和本地对白。
5. 时间必须真实产生变化：亲密、习惯、等待行为和关系阶段通过长期互动逐渐变化。
6. 它从一开始就是阿猛，而不是随机宠物；成长改变的是你们之后的关系，不覆盖阿猛原本的核心性格。

## 关系阶段

- **回来**：已经是熟悉的阿猛，但仍较克制、观察你。
- **适应**：更愿意主动靠近，也更接受互动。
- **熟悉**：日常习惯开始形成，等待和招牌亲密动作出现得更频繁。
- **回家**：形成长期稳定的依恋和日常节律，同时始终保持阿猛本来的性格。

第一版核心实现位于 `main/ameng_pet.[ch]`，刻意与 LVGL/ESP-IDF 解耦，便于在电脑上做纯逻辑单元测试。
