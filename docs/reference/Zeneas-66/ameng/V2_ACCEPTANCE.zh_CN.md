# 阿猛 V2 逐项验收表

本文用于把本轮需求与实际实现逐条对应，避免“写了但漏验”。

## 官方硬件与产品事实

- [x] 按官方仓库基线使用 ESP32-C3、8 MB Flash、无 PSRAM、240×320 屏幕和三枚实体按键。
- [x] 启用 LVGL Source Han Sans SC CJK 子集用于中文界面。
- [x] 保留“名片 / 阿猛 / 设置”的产品壳层。
- [!] 官方品牌文档说明成品 PLAY 模式可保留出厂身份卡，但公开 CREATE 基线不含出厂身份卡/小程序 BLE 同步实现，也没有身份数据分区。因此本项目实现的是本地名片与设置页，不声称兼容出厂小程序的头像/姓名同步。

## 固定菜单与中文

- [x] 五个固定菜单严格为：阿猛 / 喂食 / 抚摸 / 游戏 / 对话。
- [x] 宠物界面固定文案改为中文。
- [x] 阿猛的回答形式为不同长度和停顿的“喵” + 中文括号含义，例如“喵——（来了）”。

## 呼唤与对话规则

- [x] “阿猛”表示呼唤，任何房间均可触发。
- [x] 呼唤后一定有猫叫/文字回应。
- [x] 是否来到当前房间由好感、信任、心情、精力、饥饿、睡眠和当天重复呼唤共同影响。
- [x] “对话”只有阿猛在当前房间时可执行。
- [x] 阿猛不在当前房间时选择“对话”，显示“请先到阿猛身边”。

## 房间、时间与位置

- [x] 三个房间：卧室 / 客厅 / 书房。
- [x] 长按下键循环切换房间，切换玩家房间不会把阿猛强制瞬移过去。
- [x] 白天 9–15 点客厅/窗边概率更高，并有晒太阳行为。
- [x] 夜间更偏向卧室和睡眠。
- [x] 阿猛支持远景 / 中景 / 近景三档尺寸，并可位于画面左右不同位置。
- [x] 呼唤成功时可从画面边缘进入，并由远到近。
- [!] 当前硬件基线没有电池保持的 RTC。时间在运行和普通重启之间由逻辑时钟/NVS延续；整机彻底断电期间的真实经过时间离线无法知道。设置页提供“时间校准”。联网版后续可进一步用 NTP 校时。

## 阿猛外观与动作

- [x] 头顶左右两侧都保留淡黄色毛块。
- [x] 嘴巴左侧黄毛固定在画面左侧，不使用简单水平镜像导致换边。
- [x] 黄尾巴、浅绿眼睛、宽大的狮子头和偏胖轮廓保留。
- [x] 搭腿是独立动画：出现人腿、阿猛近景、双前爪明显抬高。
- [x] 扑鸟是独立动画：伏低 → 跃出 → 接近鸟玩具。
- [x] 另有蹭蹭、进房、晒太阳/睡眠等状态。
- [!] 当前阿猛图形由 LVGL 矢量/像素块组合，较 V1 更细致且支持远近动画，但不是照片级 RGB565 精灵图。8 MB Flash 仍有大量余量，后续拿到确定的美术素材后可以无损升级外观，而不改状态逻辑。

## 声音

- [x] 每次阿猛发声时可播放猫叫声。
- [x] 音频走 ES8311/I2S，独立任务播放，不阻塞按键回调。
- [x] 当前内置 6 种参数化短猫叫，避免占用大量 RAM。
- [x] NVS 保存延后到猫叫结束后，减少 Flash/cache 停顿导致的杂音风险。
- [!] 当前声音是合成猫叫，不是阿猛生前真实录音；若以后提供真实阿猛录音，可替换为压缩/PCM资源。

## 状态系统

### 公开的当下状态
- [x] 心情
- [x] 饥饿
- [x] 口渴
- [x] 精力
- [x] 玩心

### 公开的长期关系
- [x] 好感
- [x] 信任
- [x] 相伴天数

### 隐藏属性/记录
- [x] 熟悉度
- [x] 依恋度
- [x] 安全感
- [x] 今日呼唤/喂食/抚摸/游戏/对话次数
- [x] 今日满足度
- [x] 今日过度打扰

- [x] 长期关系按“天 + 均衡陪伴 + 有效互动”慢慢变化。
- [x] 没有“今天已达上限、禁止再按”的硬上限。
- [x] 重复操作使用收益递减；大量重复抚摸/呼唤会累积过度打扰，不能靠狂点快速刷满好感。
- [x] 喂食主要改变饥饿与当下心情，不作为快速刷好感的主要手段。
- [x] 阿猛不是从陌生猫开始；初始已有较高好感与信任，反映主人与真实阿猛已有关系，但数字仍可在新的数字生活中缓慢变化。

## 三键

| 按键 | 短按 | 长按 |
| --- | --- | --- |
| 上 | 上一个项目 | 宠物页弹出/收起状态面板 |
| 下 | 下一个项目 | 宠物页切换卧室/客厅/书房 |
| 确认 | 确认/执行 | 息屏 |

- [x] 息屏后任意实体键可唤醒。
- [x] 确认键双击从子页返回主页，保留“名片 / 阿猛 / 设置”的导航。

## AI

- [x] 本地状态是唯一权威；AI不能直接修改饥饿、好感、位置等状态。
- [x] AI只生成括号内的中文“含义”，本地再加喵声前缀。
- [x] AI提示词明确禁止编造没有档案依据的既往记忆。
- [x] AI未配置、未联网或调用失败时自动回退本地对白。

## 自动检查

- [x] Host tests 覆盖宠物状态与对白格式。
- [x] Firmware CI 使用 ESP-IDF 5.5.3 / ESP32-C3 构建并生成 merged full.bin。
- [ ] 真机视觉、猫叫音色、按键手感、中文缺字、动画节奏需要刷到实体 AI Passport 后逐项观察。
